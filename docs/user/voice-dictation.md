# Voice dictation

Use the microphone button in the message composer to dictate a draft. Select it again to stop,
then review or edit the transcript before sending it. Dictation creates composer text only; it does
not send a message or change the selected Claude, Codex, Cursor, Grok, or OpenCode provider.

In the desktop app, dictation runs on your device. The first transcription downloads a small speech
model (about 100 MB) and caches it for later use. Recorded audio and transcripts are not sent to a
speech service. Keep the app online until that first download completes.

In a supported web browser, T3 Code uses the browser's speech-recognition service. Browser support
and privacy behavior vary by browser; some browsers process recognition through an online service.
Voice input requires microphone permission and, outside the desktop app, a secure HTTPS or localhost
page.

If dictation reports that microphone permission was denied, allow microphone access for T3 Code in
your operating-system or browser settings, then try again.
